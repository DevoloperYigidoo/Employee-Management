# 👨‍💼 Employee Management System

Modern ve kullanıcı dostu bir çalışan yönetim sistemi uygulaması.

Bu proje React tabanlı geliştirilmiş olup çalışan ekleme, düzenleme, silme ve listeleme gibi temel yönetim işlemlerini gerçekleştirmek amacıyla geliştirilmiştir.

---

# 🚀 Özellikler

- 👥 Çalışan listeleme
- ➕ Yeni çalışan ekleme
- ✏️ Çalışan düzenleme
- 🗑️ Çalışan silme
- 🔐 Protected Routes yapısı
- ✅ Form doğrulama işlemleri
- 🔔 Toast bildirim sistemi
- 🎨 Modern kullanıcı arayüzü
- ✨ Animasyon destekleri

---

# 🛠️ Kullanılan Teknolojiler

## Frontend

- React 19
- Vite
- React Router DOM
- Redux Toolkit
- React Redux
- React Hook Form

## UI & Styling

- Material UI (MUI)
- Emotion React
- Emotion Styled
- Framer Motion
- Lucide React

## Notifications

- React Toastify

# ⚙️ Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak için:

```bash
git clone https://github.com/DevoloperYigidoo/Employee-Management.git
```

```bash
cd Employee-Management
```

```bash
npm install
```

```bash
npm run dev
```
